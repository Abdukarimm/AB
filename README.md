# To-Do List

This project contains a simple responsive to-do list web page and a small Node.js backend to manage tasks.

## Running the server

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

Tasks are stored in memory, so they will reset when the server restarts.
